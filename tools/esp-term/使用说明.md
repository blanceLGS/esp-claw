# esp-term 使用说明

面向 ESP32 / ESP32-S3 串口调试的桌面小工具（Windows）。

版本：**1.1.0**

---

## 一、怎么启动

### 方式 1：可执行文件（推荐）

双击：

```
tools\esp-term\dist\esp-term.exe
```

不需要安装 Python。配置和日志会放在 **exe 同目录** 的 `config.json`、`logs\`。

### 方式 2：源码启动

- 双击 `tools\esp-term\launch.vbs`（无黑框）
- 或使用 ESP-IDF 环境：

```powershell
& "C:\Espressif\tools\python\v5.5.4\venv\Scripts\pythonw.exe" `
  "D:\A-Studen\GITHUB\esp-claw\tools\esp-term\esp_term.py"
```

### 方式 3：重新打包 exe

改完 `esp_term.py` 后执行：

```
tools\esp-term\build_exe.bat
```

产物仍在 `dist\esp-term.exe`。

## 二、界面说明

### 顶部连接栏

| 控件 | 说明 |
|---|---|
| 红/绿圆点 | 离线 / 已连接 |
| **port** | 串口下拉，带 `*` 的一般是 Espressif USB |
| **↻** | 刷新串口列表 |
| **baud** | 波特率（ESP-IDF 默认 115200） |
| **Connect / Disconnect** | 连接 / 断开 |
| **RST** | 硬件复位（仅已连接时有效） |
| **rst-on-connect** | 勾选后：连接成功后自动复位一次（默认**关**） |
| **● REC / ■ STOP** | 会话日志写盘开关 |
| **log-on-connect** | 连接后自动开始写日志（默认开） |
| **⏸** | 暂停/恢复界面刷新（磁盘日志仍继续） |
| **×** | 清空当前显示 |
| **⇩** | 另存当前缓冲为文件 |

### 等级过滤（第二行）

```
lvl  [A] 全   [E] [W] [I] [D]   [—] 无标识
```

| 项 | 含义 |
|---|---|
| **A 全** | 全部接收（含无等级前缀的行） |
| **E / W / I / D** | ESP-IDF 的 Error / Warning / Info / Debug |
| **— 无标识** | 没有 `I/W/E (tag):` 前缀的 raw 行 |
| **ts** | 是否显示时间戳 |
| **scroll** | 自动滚到底 |
| **wrap** | 自动换行 |
| **log→** | 日志保存目录（可手改后回车，或点 **…** 选择） |
| **/** | 关键字过滤/高亮 |

### 发送选项（命令栏上方）

| 选项 | 说明 |
|---|---|
| **HEX显示** | 接收按 `AA BB 0D` 十六进制显示 |
| **HEX发送** | 输入框按十六进制发送（如 `48 65 6C 6C 6F`） |
| **加回车换行** | 发送时附加 EOL；取消则裸发 |
| **定时发送 + ms** | 按间隔重复发送当前输入 |

### 自定义命令按钮

命令栏上方一排按钮（help / wifi / …），点 **⚙** 可编辑：

```
标签 | 发送内容
```

每行一条，点 **Save** 保存到配置文件。

### 底部输入

- **❯** 输入框：回车发送；**↑ / ↓** 翻历史
- **eol**：LF / CRLF / None
- **Send ⏎**：同回车

## 三、常用流程

### 1. 连上开发板看日志

1. USB 连接 ESP32-S3
2. 打开 esp-term，选中带 `*` 的 COM 口，波特率 **115200**
3. 点 **Connect**
4. 若板子已在跑，日志应继续滚动；若完全没输出，点一次 **RST** 或按板上复位键

### 2. 保存本次会话日志

- 默认 **log-on-connect** 已勾选：连接后自动写  
  `<日志目录>\esp_COM3_YYYYMMDD_HHMMSS.log`
- 也可手动 **● REC** 开始 / **■ STOP** 结束

### 3. 发送 CLI 命令

连接后在底部输入例如：

```
help
wifi status
cap list
```

回车即可。设备支持的命令以固件为准。

### 4. 十六进制收发

- 看二进制：勾 **HEX显示**
- 发十六进制：勾 **HEX发送**，输入 `01 0A 0D` 等（偶数个 hex 字符）

### 5. 定时重发

1. 输入框写好内容  
2. 勾 **定时发送**，填间隔（毫秒）  
3. 再点一次或切换勾选以启动  
4. 断开会自动停止

## 四、配置文件

路径：

| 启动方式 | config.json 位置 |
|---|---|
| dist\esp-term.exe | exe 同目录 |
| 源码 / vbs | `tools\esp-term\config.json` |

关闭窗口时会保存：串口、波特率、窗口大小、过滤选项、HEX/换行/定时间隔、日志目录、自定义按钮等。

删掉 `config.json` 可恢复默认。

## 五、注意事项

1. **连接默认不会复位板子**  
   只有你点 **RST**，或勾了 **rst-on-connect** 才会拉复位脚。

2. **拔掉 USB**  
   约 1 秒内会自动变离线，并停止写日志。

3. **端口被占用**  
   关掉其它串口助手 / 旧的 esp-term / `idf.py monitor` 后再 Connect。

4. **RST 无效时**  
   部分 USB-Serial/JTAG 板对软件复位不敏感，用板上 **EN/BOOT** 键，或固件命令 `restart`。

5. **界面暂停 ⏬**  
   只停界面刷新；若正在 REC，磁盘日志仍会写满。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 打开就闪退 | 用 `launch.vbs` 或在命令行跑 exe 看报错；确认未缺少 VC 运行库 |
| Connect 失败 | 换 COM、关占用程序、检查驱动 |
| 无日志 | 确认已连接、波特率 115200、取消界面暂停；必要时 RST |
| 日志很多行看不到旧内容 | 界面只保留约 2000 行；完整内容看磁盘 log 文件 |
| HEX 发送报 invalid hex | 必须偶数位十六进制，如 `AA` `0D0A`，不要夹中文 |
